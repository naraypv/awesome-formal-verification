# Isolated LifeOS knowledge-provider proof runner

This branch contains only the three generic Quint lifecycle models copied from
`naraypv/lifeos` commit `0abf8696334e845d89239de3dfdbb27a7d8f0c43`.
No LifeOS source, configuration, credentials, vault data, or Akashic data is
included. The branch exists solely to obtain public-runner proof evidence while
private-repository jobs fail before runner allocation. The source SHA-1 values
are checked in the workflow before execution. After evidence capture, this
branch is reset to the repository main commit.
